CCDV-F（Developer – Foundations）の学習

Claude でアプリ・エージェント・ワークフローを作り、本番に出せるかを問う試験です。配点の大きい分野から順に並べています。各ページの最後の「まとめ」で要点を確認し、問題演習で定着させましょう。

53問・120分・合格 720/1000・$125

おすすめの進め方：⓪ Web 開発が初めてならはじめに（前提知識）を読む → ① 分野のページを読む → ② 問題演習で10問ずつ解く → ③ 間違えた問題の解説から、該当する章に戻る → ④「間違えた問題」モードで解き直す。

まずはここから

第0章・配点なし

はじめに：前提知識

Web アプリを作ったことがない人のための準備の章です。Claude を API で使うとはどういうことか、リクエストとレスポンス、JSON、API キー、トークンとツール利用、Python・ターミナル・Git の読み方を、実物に近いサンプルで学びます。

分野ごとの解説

配点 33.1%

アプリケーションと統合

CCDV-F で最も配点が大きい分野です。API の仕組みに加えて、要件の整理、ソフトウェア工学の基本、アプリの設計、構成管理、運用のライフサイクルまで、「本番で動かせるか」が問われます。
配点 16.8%

モデル選択と最適化

LLM の基本的な性質、SDK と API の関係、モデルの選び方、トークンと費用の管理を扱います。「なぜそう動くのか」が分かると、他の分野の問題も解きやすくなります。
配点 14.7%

エージェントとワークフロー

いつエージェントを使い、いつワークフローにするか。エージェントをどう作り、どう安全に止めるか。代表的なパターンとフレームワークまでを扱います。
配点 11.0%

プロンプトとコンテキスト

プロンプトの書き方、コンテキスト（モデルに渡す情報全体）の管理、出力の扱い方を学びます。「何を、どこに、どれだけ渡すか」がテーマです。
配点 10.6%

ツールと MCP

ツールの実装、MCP サーバーの開発、そして組み込みツール・カスタムツール・Skills・MCP の使い分けを扱います。
配点 8.1%

セキュリティと安全

プロンプトインジェクションへの対策、ガードレール、フックによる制御、シークレットの管理、個人情報の扱いを学びます。キーワードは「モデルの判断に頼らず、仕組みで守る」です。
配点 3.1%＋2.6%

Claude Code と評価・デバッグ

配点は小さい2分野ですが、Claude Code の設定は構成管理やセキュリティの問題にも登場します。デバッグの切り分けは、すべての分野の「原因を問う」問題の基礎です。

仕上げ

全分野

評価（eval）とは何か

問題文に何度も出てくる「評価」は、何を指し、具体的に何をするのか。成功基準・評価データ・採点・比較の流れを、問い合わせ分類の例で最初から最後まで追います。評価データのサンプルつき。
全分野

試験に出る用語集

インストルメンテーション、オブザーバビリティ、デプロイメント、テストセット、敵対的テストなど、問題文に出てくる専門用語を、紛らわしい用語との違いとサンプルつきで整理します。覚えたかどうかは、プラスONEチェックで確かめられます。
