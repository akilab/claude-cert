CCAR-P（Architect – Professional）の学習

本番の AI ソリューションを設計し、評価・ガバナンス・関係者との合意まで担えるかを問う試験です。CCDV-F の知識（API・ツール・プロンプト）を前提に、「判断して説明する力」が問われます。

63問・120分・合格 720/1000・$175

おすすめの進め方：① 分野のページを読む → ② 問題演習で10問ずつ解く → ③ 間違えた問題の解説から、該当する章に戻る → ④「間違えた問題」モードで解き直す。

分野ごとの解説

配点 19%

統合（Integration）

CCAR-P で最も配点が大きい分野です。権限の設計、精度と速度の判断、大規模な監視、RAG、連携方式の選択、コンテキストの読み込み方まで、「既存のシステムにどう安全につなぐか」を問います。
配点 17%

ソリューション設計

ビジネスの課題を Claude のソリューションに落とし込み、エンドツーエンドの構成、パターンの選択、マルチエージェント、分解、ビジネス価値との結びつけまでを扱います。
配点 16%

評価・テスト・最適化

何を測るか、どう測るか、どう比べるか、問題をどう診断するか、本番でどう見守るかを扱います。LLM のシステムの品質は「評価の仕組み」で決まります。
配点 14%

ガバナンス・安全・リスク

ガードレール、LLM の失敗パターン、人による確認、規制への対応、倫理面の配慮を扱います。アーキテクトとして、リスクを洗い出し、対策を設計に組み込む力が問われます。
配点 14%

関係者とのコミュニケーション・ライフサイクル

ヒアリング、トレードオフの説明、期待値の調整、文書化、ライフサイクルの支援を扱います。技術の正しさだけでなく、関係者と合意し、引き継ぎ、改善し続ける力が問われます。
配点 13%

モデル・プロンプト・コンテキスト

モデルの選び方、system プロンプトとテンプレートの設計、プロンプトの技法、コンテキストの最適化、プロンプトの再利用を、アーキテクトの視点で扱います。
配点 7%

開発生産性と運用支援

チームへの Claude Code の展開、AI を使った開発の流れ、運用上の問題の解決を扱います。CCDV-F の Claude Code の知識を、組織の視点で使う分野です。
